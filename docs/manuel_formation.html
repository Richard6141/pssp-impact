1. Super Admin

Administrateur Système — Accès total à la plateforme, y compris les fonctions techniques réservées

Permissions : 95/95  |  Visibilité : Tous les sites

1.1 Connexion et tableau de bord

Se connecter à la plateforme

  1. 1Ouvrir le navigateur et saisir l'adresse de la plateforme PSSP IMPACT+.
  2. 2Sur la page de connexion, saisir votre email ou nom d'utilisateur et votre mot de passe.
  3. 3Cliquer sur Se connecter.
  4. 4Si la double authentification (2FA) est activée, saisir le code à 6 chiffres affiché dans votre application d'authentification (Google Authenticator, Authy…).
  5. 5Vous êtes redirigé vers le tableau de bord.
[ Capture d'écran — Page de connexion ]

Tableau de bord Super Admin

Le tableau de bord affiche une vue globale de toute l'activité de la plateforme :

  • Statistiques du mois : nombre de collectes, montant des factures, revenus, sites actifs — avec comparaison par rapport au mois précédent
  • Graphique 7 derniers jours : évolution des collectes et du poids collecté
  • Répartition par type de déchet
  • Évolution sur 12 mois : collectes vs revenus
  • Activités récentes : dernières collectes, factures, paiements, incidents
  • Collectes en attente de validation et taux de validation global
  • Top 5 sites les plus actifs du mois
[ Capture d'écran — Tableau de bord Super Admin ]

1.2 Gestion des utilisateurs

Le Super Admin a accès à toutes les fonctionnalités de gestion des utilisateurs. Se reporter au chapitre 3 — Administrateur pour les procédures détaillées (création, invitation, modification, suppression), qui sont identiques pour le Super Admin.

1.3 Administration système

Ces fonctionnalités sont exclusivement réservées au Super Admin. Aucun autre rôle n'y a accès.
Accès : menu latéral Système

Consulter les logs système

Les logs enregistrent toutes les actions et erreurs techniques de la plateforme.

  1. 1Dans le menu, cliquer sur Système → Logs.
  2. 2La liste des logs s'affiche avec le niveau (ERROR, WARNING, INFO), la date et le message.
  3. 3Utiliser les filtres pour rechercher par niveau ou période.
  4. 4Cliquer sur Télécharger pour exporter le fichier de logs.
  5. 5Cliquer sur Nettoyer les logs pour archiver les anciens enregistrements.
[ Capture d'écran — Page des logs système ]

Créer une sauvegarde de la base de données

  1. 1Aller dans Système → Sauvegardes.
  2. 2Cliquer sur Créer une sauvegarde.
  3. 3Choisir si vous souhaitez compresser le fichier (recommandé).
  4. 4Confirmer. La sauvegarde SQL est générée et apparaît dans la liste.
  5. 5Cliquer sur l'icône Télécharger à côté de la sauvegarde pour la récupérer.
  6. 6Pour supprimer une ancienne sauvegarde, cliquer sur l'icône Supprimer.
[ Capture d'écran — Gestion des sauvegardes ]

Activer/désactiver le mode maintenance

  1. 1Aller dans Système → Maintenance.
  2. 2Cliquer sur Activer la maintenance. La plateforme affiche une page d'indisponibilité pour tous les utilisateurs sauf le Super Admin.
  3. 3Pour désactiver, revenir sur la même page et cliquer sur Désactiver la maintenance.
Attention : En mode maintenance, aucun utilisateur ne peut se connecter à la plateforme. N'activer ce mode que lors d'interventions techniques planifiées.

Consulter les informations système

  1. 1Aller dans Système → Informations.
  2. 2La page affiche : version PHP, version Laravel, système d'exploitation, mémoire disponible, espace disque, version MySQL et extensions PHP actives.

Optimiser la base de données

  1. 1Aller dans Système → Base de données.
  2. 2Consulter la liste des tables avec leur taille et nombre d'enregistrements.
  3. 3Cliquer sur Optimiser les tables pour améliorer les performances.

Vider le cache

  1. 1Aller dans Système → Cache.
  2. 2Cliquer sur Vider le cache. Tous les caches (configuration, vues, routes, application) sont effacés.
Vider le cache est utile après modification de la configuration ou lors de comportements inattendus de la plateforme.

2. Coordonnateur

Directeur Opérationnel — Supervise l'ensemble du cycle collecte → facturation → paiement

Permissions : ~87/95 (tout sauf system.*)  |  Visibilité : Tous les sites

2.1 Tableau de bord

Après connexion, le Coordonnateur accède à un tableau de bord complet identique à celui du Super Admin :

  • Statistiques globales du mois (collectes, factures, revenus)
  • Collectes en attente de sa validation finale
  • Factures impayées et paiements en attente
  • Top 5 sites actifs, activités récentes
  • Graphiques d'évolution mensuelle
[ Capture d'écran — Tableau de bord Coordonnateur ]

2.2 Supervision et validation des collectes

Consulter la liste des collectes

Collectes dans le menu latéral
  1. 1Cliquer sur Collectes dans le menu.
  2. 2La liste affiche toutes les collectes de tous les sites avec : numéro, date, poids, type de déchet, agent, site, statut de signature (responsable site) et statut de validation finale.
  3. 3Les colonnes Signature Resp. et Coord. Approbation permettent de voir rapidement l'avancement de chaque collecte.
[ Capture d'écran — Liste des collectes avec colonnes de validation ]

Effectuer la validation finale d'une collecte

La validation finale est l'action la plus importante du Coordonnateur. Elle rend la collecte factorisable.

Prérequis : La collecte doit avoir été préalablement signée par le Responsable Site (colonne Signature Resp. affiche une coche verte).
  1. 1Dans la liste des collectes, repérer une collecte avec la signature du responsable site.
  2. 2Cliquer sur le bouton Valider (icône cercle vert ✓) dans la colonne Actions.
  3. 3Une confirmation apparaît : "Voulez-vous vraiment valider cette collecte ?"
  4. 4Cliquer sur Oui, valider.
  5. 5La colonne Coord. Approbation passe à ✔ (vert). La collecte est maintenant factorisable.
[ Capture d'écran — Bouton de validation finale dans la liste des collectes ]
Résultat : La collecte est désormais éligible à la facturation. Le Comptable pourra l'inclure dans une facture.

Invalider une collecte

Si une collecte validée doit être corrigée, le Coordonnateur peut annuler la validation.

  1. 1Dans la liste des collectes, repérer la collecte déjà validée (✔ vert dans Coord. Approbation).
  2. 2Cliquer sur le bouton Invalider (icône X rouge) dans la colonne Actions.
  3. 3Confirmer l'invalidation.
Attention : Une collecte déjà incluse dans une facture ne peut pas être invalidée. Il faut d'abord supprimer ou modifier la facture.

Modifier ou supprimer une collecte

  1. 1Dans la liste, cliquer sur l'icône Modifier (crayon jaune) ou Supprimer (poubelle rouge).
  2. 2Pour la modification : corriger les informations et cliquer sur Enregistrer.
  3. 3Pour la suppression : confirmer dans la boîte de dialogue.
Impossible de supprimer une collecte qui est déjà incluse dans une facture ou qui a déjà été validée par le responsable site.

2.3 Gestion des factures

Le Coordonnateur a accès complet aux factures (voir aussi le chapitre 4 — Comptable pour les procédures détaillées).

Créer une facture

Factures → bouton +
  1. 1Cliquer sur Factures dans le menu.
  2. 2Cliquer sur le bouton + (nouveau).
  3. 3Sélectionner le site client à facturer. La liste des collectes éligibles se charge automatiquement.
  4. 4Cocher les collectes à inclure dans la facture.
  5. 5Renseigner le montant, la date de facture et la date d'échéance.
  6. 6Joindre un document optionnel (scan de facture papier).
  7. 7Cliquer sur Créer la facture.
[ Capture d'écran — Formulaire de création de facture ]

Envoyer une facture au client

  1. 1Dans la liste des factures, cliquer sur l'icône Envoyer (enveloppe).
  2. 2Confirmer l'envoi. La facture est transmise par email au Responsable Site du client.
  3. 3Le statut de la facture passe à envoyée.

2.4 Gestion des paiements

Le Coordonnateur peut valider les paiements et générer les reçus (voir aussi chapitre 4 — Comptable).

Valider un paiement

Paiements → cliquer sur un paiement avec statut nouveau
  1. 1Dans la liste des paiements, repérer les paiements avec le statut nouveau.
  2. 2Cliquer sur le bouton Valider.
  3. 3Un reçu PDF est généré automatiquement. Vous pouvez aussi uploader un reçu existant.
  4. 4Confirmer la validation.
  5. 5Le paiement passe à validé et la facture correspondante passe à payée.
[ Capture d'écran — Validation d'un paiement ]

2.5 Rapports et statistiques

Rapports dans le menu latéral

Rapport des collectes

  1. 1Cliquer sur Rapports → Collectes.
  2. 2Définir les filtres : période (date début / date fin), site, agent, type de déchet, statut.
  3. 3Cliquer sur Générer. Le rapport affiche le total des collectes, poids, taux de validation, top agents.
  4. 4Cliquer sur Exporter PDF ou Exporter TXT pour télécharger.
[ Capture d'écran — Rapport des collectes avec filtres ]

Rapport financier

  1. 1Cliquer sur Rapports → Financier.
  2. 2Appliquer les filtres souhaités (période, site, statut de facture, mode de paiement).
  3. 3Consulter : revenus totaux, factures émises, paiements reçus, montant impayé.
  4. 4Exporter en PDF ou Excel.
[ Capture d'écran — Rapport financier ]

Rapport par sites

  1. 1Cliquer sur Rapports → Sites.
  2. 2Filtrer par département, commune ou période.
  3. 3Consulter les statistiques par site : collectes, poids, chiffre d'affaires, observations.
  4. 4Exporter en PDF.

2.6 Gestion des incidents et observations

Consulter et résoudre un incident

Incidents dans le menu latéral
  1. 1Cliquer sur Incidents.
  2. 2La liste affiche tous les incidents avec leur statut : ouvert, en cours, fermé.
  3. 3Cliquer sur un incident pour le consulter.
  4. 4Cliquer sur Marquer en cours pour prendre en charge.
  5. 5Cliquer sur Résoudre pour fermer l'incident une fois traité.
[ Capture d'écran — Gestion des incidents ]

3. Administrateur

Gestionnaire Technique — Configure et administre la plateforme, les utilisateurs et les sites

Permissions : ~35/95  |  Visibilité : Tous les sites

3.1 Gérer les utilisateurs

Utilisateurs dans le menu latéral

Consulter la liste des utilisateurs

  1. 1Cliquer sur Utilisateurs dans le menu.
  2. 2La liste affiche tous les comptes avec : nom, email, rôle, site, statut (actif/inactif).
  3. 3Utiliser les filtres en haut pour rechercher par nom, rôle, statut ou site.
[ Capture d'écran — Liste des utilisateurs avec filtres ]

Créer un nouvel utilisateur

  1. 1Cliquer sur le bouton + en haut à droite de la liste.
  2. 2Remplir le formulaire avec les informations suivantes :
  • Prénom Obligatoire
  • Nom Obligatoire
  • Nom d'utilisateur Obligatoire — sert à la connexion, doit être unique
  • Email Obligatoire — doit être unique
  • Mot de passe Obligatoire — minimum 8 caractères
  • Confirmation mot de passe Obligatoire
  • Rôle Obligatoire — Agent collecte, Comptable, etc.
  • Site principal Optionnel — site de rattachement hiérarchique
  • Définir comme responsable Optionnel — cocher pour affecter cet utilisateur comme responsable du site
  • Sites autorisés Optionnel — maintenir Ctrl pour sélectionner plusieurs sites
  • Téléphone, Entreprise, Poste Optionnel
  • Photo de profil Optionnel — JPG ou PNG
  • Compte actif Optionnel — coché par défaut
  1. 3Cliquer sur Créer. L'utilisateur peut maintenant se connecter.
[ Capture d'écran — Formulaire de création d'utilisateur ]

Modifier un utilisateur

  1. 1Dans la liste, cliquer sur l'icône Modifier (crayon) de l'utilisateur concerné.
  2. 2Modifier les champs souhaités. Pour le mot de passe : laisser vide si inchangé, ou saisir un nouveau mot de passe.
  3. 3Cliquer sur Mettre à jour.

Activer ou désactiver un compte

  1. 1Dans la liste des utilisateurs, cliquer sur le bouton de statut (interrupteur vert/rouge) de l'utilisateur.
  2. 2Le statut bascule immédiatement. Un utilisateur désactivé ne peut plus se connecter mais ses données sont conservées.
La désactivation est préférable à la suppression pour conserver l'historique des actions de l'utilisateur.

Supprimer un utilisateur

  1. 1Dans la liste, cliquer sur l'icône Supprimer (poubelle rouge).
  2. 2Confirmer dans la boîte de dialogue.
Impossible de supprimer un utilisateur ayant des données associées (collectes, factures, observations, incidents, validations). Désactiver le compte à la place.

Exporter la liste des utilisateurs

  1. 1En haut de la liste, cliquer sur Exporter CSV.
  2. 2Le fichier CSV contenant tous les utilisateurs est téléchargé (nom, email, rôle, site, statut, date de création).

Importer des utilisateurs en masse (CSV)

  1. 1Cliquer sur Importer CSV en haut de la liste.
  2. 2Télécharger le template CSV pour avoir le bon format de fichier.
  3. 3Remplir le fichier avec les colonnes : firstname, lastname, email, username, role, site_id.
  4. 4Uploader le fichier rempli et cliquer sur Importer.
  5. 5Un résumé indique le nombre de comptes créés et les éventuelles erreurs (email déjà utilisé, rôle inexistant…).
[ Capture d'écran — Import CSV utilisateurs ]

3.2 Inviter un utilisateur par email

L'invitation permet à un futur utilisateur de créer son propre mot de passe et de configurer son accès.

Utilisateurs → Invitations

Envoyer une invitation

  1. 1Aller dans Utilisateurs → Invitations.
  2. 2Cliquer sur le bouton + (Nouvelle invitation).
  3. 3Saisir l'adresse email de la personne à inviter.
  4. 4Sélectionner le rôle qui lui sera attribué.
  5. 5Sélectionner optionnellement un site et cocher "Définir comme responsable du site" si nécessaire.
  6. 6Cliquer sur Envoyer l'invitation.
  7. 7L'email est envoyé immédiatement. L'invitation est valable 48 heures.
[ Capture d'écran — Formulaire d'invitation ]

Ce que reçoit la personne invitée

L'invité reçoit un email avec un lien. En cliquant dessus :

  1. 1Il arrive sur une page qui lui indique son adresse email et son rôle.
  2. 2Il remplit : prénom, nom, nom d'utilisateur et mot de passe.
  3. 3Il clique sur Créer mon compte. Son accès est immédiat.
[ Capture d'écran — Page d'acceptation d'invitation ]

Renvoyer une invitation expirée

  1. 1Dans la liste des invitations, repérer l'invitation expirée ou en attente.
  2. 2Cliquer sur Renvoyer. Un nouveau lien valable 48h est envoyé.

3.3 Gérer les sites

Sites dans le menu latéral

Créer un site

  1. 1Cliquer sur Sites → bouton +.
  2. 2Remplir le formulaire :
  • Code site Obligatoire — identifiant unique (ex: CHU-001)
  • Nom du site Obligatoire
  • Département Obligatoire
  • Commune Obligatoire
  • Localisation Optionnel
  • Latitude / Longitude Optionnel — coordonnées GPS
  • Responsable Optionnel — utilisateur Responsable Site
  1. 3Cliquer sur Enregistrer.
[ Capture d'écran — Formulaire de création de site ]

Modifier un site

  1. 1Dans la liste des sites, cliquer sur l'icône Modifier.
  2. 2Mettre à jour les informations et cliquer sur Enregistrer.

Importer des sites en masse (CSV)

  1. 1Dans la page Sites, cliquer sur Importer des sites.
  2. 2Télécharger le template CSV.
  3. 3Remplir le fichier (colonnes : site_code, site_name, site_departement, site_commune, localisation, latitude, longitude, responsable_email).
  4. 4Uploader et cliquer sur Importer.

Supprimer un site

  1. 1Dans la liste, cliquer sur l'icône Supprimer.
  2. 2Confirmer.
Un site ne peut être supprimé que s'il n'a aucune collecte enregistrée.

3.4 Configuration de la plateforme

Gérer les types de déchets

Configuration → Types de déchets
  1. 1Cliquer sur Configuration → Types de déchets.
  2. 2Pour créer : cliquer sur +, saisir le libellé, le code et la description, puis valider.
  3. 3Pour modifier : cliquer sur le crayon, modifier et valider.
  4. 4Pour supprimer : cliquer sur la poubelle (impossible si le type est utilisé dans des collectes).
[ Capture d'écran — Gestion des types de déchets ]

Gérer les rôles et permissions

Configuration → Rôles et permissions
  1. 1Créer un nouveau rôle : cliquer sur Nouveau rôle, saisir le nom, valider.

  3. 3Supprimer un rôle : cliquer sur Supprimer (impossible pour le rôle Super Admin).
Modifier les permissions d'un rôle affecte immédiatement tous les utilisateurs ayant ce rôle.

Consulter le journal d'audit

Audit dans le menu (section Administration)
  1. 1Cliquer sur Audit.
  2. 2La liste affiche toutes les actions effectuées : qui, quoi, quand.
  3. 3Filtrer par utilisateur, type d'action ou période.
  4. 4Cliquer sur Exporter CSV pour télécharger le journal.
  5. 5Cliquer sur Nettoyer pour supprimer les logs plus anciens qu'un certain nombre de jours.
[ Capture d'écran — Journal d'audit ]

Gérer les sessions actives

Administration → Sessions
  1. 1Consulter la liste de toutes les sessions actives (utilisateur, appareil, IP, dernière activité).
  2. 2Cliquer sur Terminer pour mettre fin à une session spécifique (déconnexion forcée).

4. Comptable

Gestionnaire Financier — Crée les factures, valide les paiements, génère les reçus et les rapports

Permissions : ~15/95  |  Visibilité : Tous les sites

4.1 Tableau de bord

Le Comptable accède à un tableau de bord orienté finances :

  • Total des factures et montant du mois
  • Paiements reçus et montant encaissé
  • Factures impayées en attente
  • Top 5 sites par revenus
  • Évolution mensuelle des encaissements
[ Capture d'écran — Tableau de bord Comptable ]

4.2 Créer et gérer les factures

Factures dans le menu latéral

Créer une facture

Prérequis : Les collectes à facturer doivent être signées par le Responsable Site ET validées par le Coordonnateur. La plateforme filtre automatiquement les collectes éligibles.
  1. 1Cliquer sur Factures → bouton +.
  2. 2Sélectionner le site client à facturer dans la liste déroulante.
  3. 3La liste des collectes éligibles du site se charge automatiquement. Vérifier les collectes disponibles.
  4. 4Cocher les collectes à inclure dans cette facture.
  5. 5Saisir le montant total de la facture.
  6. 6Saisir la date de la facture et la date d'échéance.
  7. 7Joindre optionnellement un document (scan de facture papier, format JPG/PNG/PDF).
  8. 8Cliquer sur Créer la facture.
[ Capture d'écran — Formulaire de création de facture avec sélection des collectes ]
Résultat : La facture est créée avec le numéro automatique (FAC-YYYY-XXXX) et le statut en attente. Les collectes incluses ne pourront plus être ajoutées à une autre facture.

Envoyer une facture par email au client

  1. 1Dans la liste des factures, repérer la facture à envoyer.
  2. 2Cliquer sur l'icône Envoyer (enveloppe).
  3. 3Confirmer l'envoi. L'email est transmis au Responsable Site du client.
  4. 4Le statut passe à envoyée.

Modifier une facture

  1. 1Dans la liste, cliquer sur l'icône Modifier (crayon).
  2. 2Modifier le montant, la date d'échéance ou les collectes incluses.
  3. 3Cliquer sur Enregistrer.
Une facture ayant un paiement associé ne peut pas être modifiée. Annuler d'abord le paiement si nécessaire.

Supprimer une facture

  1. 1Dans la liste, cliquer sur l'icône Supprimer.
  2. 2Confirmer dans la boîte de dialogue.
Impossible de supprimer une facture liée à un paiement. Annuler ou supprimer le paiement d'abord.

4.3 Gérer les paiements

Paiements dans le menu latéral

Enregistrer un paiement reçu

  1. 1Cliquer sur Paiements → bouton +.
  2. 2Remplir le formulaire :
  • Facture Obligatoire — sélectionner la facture concernée
  • Montant Obligatoire — peut être partiel (paiement partiel possible)
  • Date de paiement Obligatoire
  • Mode de paiement Obligatoire — chèque, virement, espèces, mobile money…
  • Preuve de paiement Optionnel — photo du chèque ou justificatif
  1. 3Cliquer sur Enregistrer. Le paiement est en statut nouveau.
[ Capture d'écran — Formulaire d'enregistrement de paiement ]

Valider un paiement et générer le reçu

Après vérification du paiement reçu, le Comptable le valide officiellement.

  1. 1Dans la liste des paiements, repérer ceux au statut nouveau.
  2. 2Cliquer sur le bouton Valider.
  3. 3Optionnellement uploader un reçu existant (PDF). Sinon, un reçu est généré automatiquement.
  4. 4Confirmer la validation.
Résultat :
• Le paiement passe au statut validé
• Un reçu PDF est généré (numéro CCP-XXXX)
• La facture passe au statut payée (si montant total atteint)
• Le reçu est disponible en téléchargement pour le Responsable Site
[ Capture d'écran — Validation du paiement et génération du reçu ]

Télécharger un reçu

  1. 1Dans la liste des paiements, repérer un paiement validé.
  2. 2Cliquer sur l'icône Télécharger le reçu.
  3. 3Le PDF est téléchargé sur votre ordinateur.

Annuler un paiement

  1. 1Dans la liste, cliquer sur l'icône Annuler (X).
  2. 2Confirmer l'annulation.
Résultat : Le paiement passe au statut rejeté. La facture repasse au statut en attente.

4.4 Rapports financiers et export comptable

Rapport financier

  1. 1Aller dans Rapports → Financier.
  2. 2Définir la période et les filtres (site, statut facture, mode paiement).
  3. 3Consulter : revenus totaux, factures émises vs payées, montants impayés, top sites.
  4. 4Exporter en PDF (rapport formaté) ou Excel (données brutes).
[ Capture d'écran — Rapport financier ]

Journal comptable

  1. 1Aller dans Comptabilité → Journal.
  2. 2Consulter les écritures comptables (débit/crédit pour chaque facture et paiement).
  3. 3Filtrer par type de pièce (facture/paiement) ou période.
  4. 4Cliquer sur Exporter PDF.

Exporter les données comptables

  1. 1Aller dans Comptabilité → Export.
  2. 2Choisir le format : CSV, Excel (.xlsx) ou TXT (pour logiciels comptables tiers).
  3. 3Cliquer sur le bouton d'export correspondant. Le fichier est téléchargé.

Agent de Collecte
Enregistrement des collectes et signalements terrain
5.1 Connexion et Tableau de Bord

L'agent de collecte se connecte avec ses identifiants pour accéder au tableau de bord dédié à ses activités terrain.

Connexion à la plateforme
  1. Ouvrir le navigateur et aller sur l'URL de la plateforme.
  2. Entrer votre adresse email et mot de passe.
  3. Cliquer sur « Se connecter ».
  4. Le tableau de bord s'affiche avec vos activités récentes.
Ce que vous voyez sur votre tableau de bord :
  • Collectes du jour : Nombre de collectes enregistrées aujourd'hui.
  • Collectes cette semaine : Total de la semaine en cours.
  • Collectes en attente : Collectes non encore validées par le responsable.
  • Incidents ouverts : Incidents que vous avez signalés et non résolus.
[CAPTURE — Tableau de bord agent de collecte]
5.2 Enregistrer une Collecte

Après chaque passage sur un site, vous devez enregistrer la collecte dans le système.

Étape 1 — Accéder au formulaire de collecte
  1. Dans le menu de gauche, cliquer sur « Collectes ».
  2. Cliquer sur le bouton « + Nouvelle collecte » en haut à droite.
  3. Le formulaire de saisie s'ouvre.
[CAPTURE — Bouton « + Nouvelle collecte »]
Étape 2 — Remplir les informations de la collecte
  1. Sélectionner le site concerné dans la liste déroulante (seuls vos sites assignés apparaissent).
  2. Vérifier la date de collecte (pré-remplie avec la date du jour, modifiable si nécessaire).
  3. Entrer le volume collecté en kg ou en m³ selon le site.
  4. Sélectionner le type de déchets (ménagers, industriels, recyclables, etc.).
  5. Renseigner le nombre de ménages ou de points de collecte visités.
  6. Indiquer le véhicule utilisé (si applicable).
  7. Ajouter des observations dans le champ texte (incidents mineurs, difficultés d'accès, etc.).
[CAPTURE — Formulaire de saisie d'une collecte]
Étape 3 — Valider la collecte
  1. Vérifier toutes les informations saisies.
  2. Cliquer sur « Enregistrer ».
  3. Un message de confirmation s'affiche : « Collecte enregistrée avec succès ».
  4. La collecte apparaît maintenant dans la liste avec le statut En attente.
Important : Une collecte enregistrée est en statut En attente jusqu'à validation par le responsable de site. Une fois validée, elle ne peut plus être modifiée.
[CAPTURE — Liste des collectes avec statuts]
5.3 Modifier ou Supprimer une Collecte

Vous pouvez corriger ou annuler une collecte que vous avez enregistrée, tant qu'elle n'a pas été validée.

Modifier une collecte en attente
  1. Aller dans « Collectes ».
  2. Repérer la collecte à modifier (statut En attente).
  3. Cliquer sur l'icône crayon (modifier) à droite de la ligne.
  4. Corriger les informations nécessaires.
  5. Cliquer sur « Enregistrer ».
Restriction : Si la collecte a été validée (statut Validée), le bouton de modification n'est plus disponible. Contactez le responsable de site si une correction est nécessaire.
Supprimer une collecte en attente
  1. Aller dans « Collectes ».
  2. Repérer la collecte à supprimer.
  3. Cliquer sur l'icône corbeille (supprimer).
  4. Confirmer la suppression dans la boîte de dialogue.
[CAPTURE — Icônes modifier/supprimer sur une collecte]
5.4 Signaler un Incident

En cas de problème sur le terrain (éboulements, accès bloqué, bagarre, matériel endommagé, etc.), vous pouvez signaler un incident directement depuis la plateforme.

Créer un signalement d'incident
  1. Dans le menu de gauche, cliquer sur « Incidents ».
  2. Cliquer sur « + Signaler un incident ».
  3. Sélectionner le site concerné.
  4. Choisir le type d'incident dans la liste (obstacle, accident, équipement, sécurité, autre).
  5. Indiquer le niveau de gravité (Faible / Moyen / Élevé / Critique).
  6. Décrire l'incident dans le champ « Description » (soyez précis : lieu, heure, personnes impliquées).
  7. Si possible, ajouter une photo en pièce jointe.
  8. Cliquer sur « Soumettre ».
Après soumission : L'incident reçoit le statut Ouvert. Le responsable de site et le coordonnateur sont notifiés. Vous pouvez suivre l'évolution de l'incident dans la liste.
[CAPTURE — Formulaire de signalement d'incident]
Suivre vos incidents signalés
  1. Aller dans « Incidents ».
  2. La liste affiche tous les incidents que vous avez signalés.
  3. Les statuts possibles sont : Ouvert, En cours, Résolu, Fermé.
  4. Cliquer sur l'icône œil (voir) pour consulter les détails et les commentaires.
[CAPTURE — Liste des incidents avec statuts]
5.5 Ajouter une Observation

Les observations permettent de noter des remarques qualitatives sur l'état d'un site ou d'une collecte (propreté, comportement des ménages, problèmes récurrents, etc.).

Créer une observation
  1. Dans le menu de gauche, cliquer sur « Observations ».
  2. Cliquer sur « + Nouvelle observation ».
  3. Sélectionner le site concerné.
  4. Choisir la catégorie de l'observation (Hygiène, Participation, Infrastructure, Autre).
  5. Écrire votre observation dans le champ « Contenu ».
  6. Cliquer sur « Enregistrer ».
[CAPTURE — Formulaire d'observation]
5.6 Consulter Mes Collectes

Vous pouvez consulter l'historique de toutes vos collectes et suivre leur statut de validation.

Consulter la liste des collectes
  1. Aller dans « Collectes ».
  2. Par défaut, la liste affiche vos collectes récentes.
  3. Utiliser les filtres en haut pour rechercher par date, site ou statut.
  4. Cliquer sur l'icône œil (voir) pour consulter le détail d'une collecte.
Signification des statuts :
  • En attente : Saisie enregistrée, en attente de validation par le responsable.
  • Validée : Collecte approuvée par le responsable de site.
  • Rejetée : Collecte refusée avec un motif de rejet.
  • Double validation : Validée par le responsable ET le coordonnateur (éligible à facturation).
[CAPTURE — Historique des collectes avec filtres]
6
Responsable de Site
Validation des collectes, supervision terrain et facturation site
6.1 Connexion et Tableau de Bord

Le responsable de site supervise les opérations de collecte sur son ou ses sites assignés. Son tableau de bord centralise toutes les actions prioritaires.

Connexion et accueil
  1. Se connecter à la plateforme avec vos identifiants.
  2. Le tableau de bord affiche les indicateurs de votre site.
Indicateurs du tableau de bord :
  • Collectes en attente de validation : Nombre de collectes soumises par les agents à valider.
  • Collectes validées ce mois : Total des collectes approuvées.
  • Factures en attente : Factures émises non encore payées.
  • Paiements en attente : Paiements reçus non encore confirmés.
  • Incidents ouverts : Incidents signalés sur votre site.
[CAPTURE — Tableau de bord responsable de site]
6.2 Valider les Collectes (1ère Validation)

Lorsqu'un agent enregistre une collecte, elle doit être validée par le responsable de site. C'est la première étape du processus de validation en deux niveaux.

Étape 1 — Voir les collectes en attente
  1. Aller dans « Collectes ».
  2. Filtrer par statut En attente pour voir uniquement celles à traiter.
  3. Ou cliquer directement sur le compteur du tableau de bord.
[CAPTURE — Filtre collectes en attente]
Étape 2 — Examiner une collecte
  1. Cliquer sur l'icône œil (voir) à droite d'une collecte.
  2. Vérifier les informations : site, date, volume, agent, observations.
  3. S'assurer que les données sont cohérentes avec la réalité terrain.
Étape 3 — Valider ou Rejeter
  1. Pour valider : Cliquer sur le bouton « Valider » (icône ✓ verte).
  2. La collecte passe au statut Validée.
  3. Pour rejeter : Cliquer sur le bouton « Rejeter » (icône ✗ rouge).
  4. Entrer le motif de rejet dans la boîte de dialogue.
  5. Confirmer le rejet. L'agent est informé du rejet et de son motif.
Après votre validation : La collecte passe en statut Validée et est transmise au coordonnateur pour la 2ème validation. Seules les collectes ayant reçu les deux validations sont éligibles à la facturation.
[CAPTURE — Boutons Valider / Rejeter sur une collecte]
6.3 Signer une Collecte

En plus de la validation, le responsable peut apposer une signature électronique sur une collecte pour authentifier son approbation.

Signer une collecte validée
  1. Ouvrir le détail d'une collecte validée.
  2. Cliquer sur le bouton « Signer ».
  3. Un canvas de signature s'affiche. Dessiner votre signature avec la souris ou le doigt (tablette).
  4. Cliquer sur « Valider la signature ».
  5. La signature est enregistrée et affichée sur la fiche de collecte.
[CAPTURE — Zone de signature électronique]
6.4 Gérer les Factures

Le responsable de site peut consulter et gérer les factures liées à son site.

Consulter les factures de mon site
  1. Aller dans « Factures ».
  2. La liste affiche uniquement les factures de votre site.
  3. Cliquer sur l'icône œil pour voir le détail d'une facture.
  4. Cliquer sur l'icône PDF pour télécharger la facture en PDF.
[CAPTURE — Liste des factures du site]
Créer une facture manuelle
  1. Cliquer sur « + Nouvelle facture ».
  2. Sélectionner la période de facturation (mois/année).
  3. Le système propose automatiquement les collectes doublement validées de la période.
  4. Vérifier le montant calculé.
  5. Cliquer sur « Émettre la facture ».
Note : Seules les collectes ayant reçu la double validation (responsable + coordonnateur) sont incluses dans les factures.
6.5 Enregistrer un Paiement Reçu

Lorsque vous recevez un paiement d'un client pour une facture, vous devez l'enregistrer dans le système.

Enregistrer un paiement
  1. Aller dans « Paiements ».
  2. Cliquer sur « + Nouveau paiement ».
  3. Sélectionner la facture concernée dans la liste.
  4. Entrer le montant reçu.
  5. Sélectionner le mode de paiement (espèces, virement, mobile money, chèque).
  6. Entrer la date de réception du paiement.
  7. Ajouter une référence de transaction si disponible (numéro de virement, etc.).
  8. Cliquer sur « Enregistrer ».
Après enregistrement : Le paiement est en statut En attente de confirmation. Le comptable ou le coordonnateur doit confirmer le paiement pour mettre à jour le statut de la facture.
[CAPTURE — Formulaire d'enregistrement de paiement]
6.6 Gérer les Incidents du Site

En tant que responsable, vous supervisez tous les incidents signalés sur votre site et êtes responsable de leur traitement.

Traiter un incident signalé
  1. Aller dans « Incidents ».
  2. Consulter la liste des incidents de votre site.
  3. Cliquer sur l'icône œil pour voir le détail d'un incident.
  4. Changer le statut en En cours pour indiquer que vous prenez en charge.
  5. Ajouter un commentaire décrivant les actions entreprises.
  6. Une fois l'incident résolu, changer le statut en Résolu.
  7. Ajouter une note de clôture expliquant la résolution.
[CAPTURE — Gestion d'un incident avec changement de statut]
6.7 Ajouter et Gérer les Observations

Le responsable peut ajouter des observations sur son site et consulter celles faites par les agents.

Créer une observation
  1. Aller dans « Observations ».
  2. Cliquer sur « + Nouvelle observation ».
  3. Le site est pré-sélectionné sur votre site.
  4. Choisir la catégorie et rédiger l'observation.
  5. Cliquer sur « Enregistrer ».
Modifier ou supprimer une observation
  1. Dans la liste des observations, vous pouvez modifier et supprimer uniquement vos propres observations.
  2. Cliquer sur l'icône crayon pour modifier, ou corbeille pour supprimer.
  3. Les observations des agents sont visibles en lecture seule.
[CAPTURE — Liste des observations avec filtres par auteur]
6.8 Consulter les Rapports du Site

Le responsable a accès à des rapports de performance pour son site.

Accéder aux rapports
  1. Aller dans « Rapports ».
  2. Sélectionner la période à analyser (semaine, mois, trimestre, personnalisé).
  3. Les rapports disponibles : Collectes par période, Taux de validation, Revenus et paiements.
  4. Cliquer sur « Générer » pour afficher le rapport.
  5. Cliquer sur « Exporter PDF » ou « Exporter Excel » pour télécharger.
[CAPTURE — Interface de génération de rapports]

Agent Santé
Surveillance hygiénique et gestion des incidents sanitaires
7.1 Connexion et Tableau de Bord

L'agent santé est chargé de surveiller les conditions hygiéniques des sites et de gérer les incidents sanitaires. Son accès est centré sur les observations et les incidents de nature sanitaire.

Connexion à la plateforme
  1. Se connecter avec vos identifiants.
  2. Le tableau de bord affiche les indicateurs sanitaires.
Indicateurs du tableau de bord :
  • Incidents sanitaires ouverts : Incidents nécessitant une intervention.
  • Observations récentes : Dernières observations hygiéniques enregistrées.
  • Sites à risque : Sites avec incidents sanitaires non résolus.
  • Interventions planifiées : Visites sanitaires à effectuer.
[CAPTURE — Tableau de bord agent santé]
7.2 Enregistrer une Observation Hygiénique

Après une inspection d'un site, vous devez enregistrer vos observations sur les conditions sanitaires.

Créer une observation sanitaire
  1. Dans le menu, cliquer sur « Observations ».
  2. Cliquer sur « + Nouvelle observation ».
  3. Sélectionner le site inspecté.
  4. Choisir la catégorie « Hygiène » ou « Sanitaire ».
  5. Décrire les conditions observées dans le champ « Contenu » :
    • État de propreté général du site.
    • Présence d'odeurs ou de nuisibles.
    • Respect des normes de collecte.
    • Risques sanitaires identifiés.
  6. Indiquer un niveau de risque si le formulaire le permet.
  7. Cliquer sur « Enregistrer ».
[CAPTURE — Formulaire d'observation hygiénique]
7.3 Signaler un Incident Sanitaire

En cas de problème sanitaire grave (épidémie potentielle, contamination, infestation de nuisibles), vous devez créer un incident prioritaire.

Créer un incident sanitaire
  1. Aller dans « Incidents ».
  2. Cliquer sur « + Signaler un incident ».
  3. Sélectionner le site concerné.
  4. Choisir le type « Sanitaire » ou « Hygiène ».
  5. Sélectionner le niveau de gravité approprié :
    • Faible : Inconfort mineur, pas de risque immédiat.
    • Moyen : Risque potentiel, intervention recommandée.
    • Élevé : Risque avéré, intervention urgente nécessaire.
    • Critique : Danger immédiat, escalade immédiate requise.
  6. Rédiger une description détaillée : symptômes observés, nombre de personnes affectées, localisation précise.
  7. Joindre des photos si disponibles.
  8. Cliquer sur « Soumettre ».
Urgence sanitaire : Pour les incidents de niveau Critique, contactez également par téléphone le responsable de site et le coordonnateur. N'attendez pas qu'ils consultent la plateforme.
[CAPTURE — Signalement d'incident sanitaire critique]
7.4 Suivre et Mettre à Jour les Incidents

Vous suivez l'évolution des incidents sanitaires que vous avez signalés et pouvez ajouter des mises à jour.

Mettre à jour un incident en cours
  1. Aller dans « Incidents ».
  2. Cliquer sur l'icône œil de l'incident à mettre à jour.
  3. Dans la section « Commentaires », ajouter votre mise à jour.
  4. Décrire : actions prises, évolution de la situation, résultats des mesures.
  5. Cliquer sur « Ajouter commentaire ».
[CAPTURE — Section commentaires d'un incident]
7.5 Consulter les Collectes (Lecture)

L'agent santé peut consulter les collectes pour évaluer les tendances sanitaires liées aux volumes et fréquences de collecte.

Consulter les collectes en lecture
  1. Aller dans « Collectes ».
  2. Utiliser les filtres par site et par période pour analyser les données.
  3. Les collectes sont visibles en lecture seule — vous ne pouvez pas les modifier.
  4. Utiliser ces données pour identifier les sites sous-collectés (accumulation de déchets = risque sanitaire).
Usage recommandé : Croiser la fréquence des collectes avec vos observations sanitaires pour identifier les corrélations entre irrégularités de collecte et problèmes d'hygiène.
[CAPTURE — Vue collectes en lecture pour agent santé]

Indicateurs du tableau de bord :

L'agent marketing consulte les données de collectes pour analyser les performances par site et identifier les tendances.

8.3 Suivi des Factures et Recouvrement

Le suivi des factures impayées est une mission clé de l'agent marketing pour optimiser le taux de recouvrement.

Identifier les factures impayées
  1. Aller dans « Factures ».
  2. Filtrer par statut Impayée ou En retard.
  3. Trier par date d'échéance pour voir les plus urgentes en premier.
  4. Consulter le détail d'une facture en cliquant sur l'icône œil.

  3. Enregistrer la tentative de contact dans les observations liées au site.
  4. Suivre l'évolution du paiement dans la liste des factures.
Note : L'agent marketing peut consulter les factures et paiements en lecture. Il ne peut pas créer ni modifier les factures — cette action est réservée au responsable de site et au comptable.

La génération de rapports est la principale activité analytique de l'agent marketing.

Générer un rapport de performance

    • Rapport d'activité : Synthèse globale de la période.
  3. Sélectionner la période (semaine, mois, trimestre, année, personnalisé).
  4. Sélectionner les sites à inclure (tous ou sélection).
  5. Cliquer sur « Générer ».
[CAPTURE — Interface de sélection des rapports]
Exporter et partager un rapport

Consulter la liste des sites

Annexe — Gestion du Profil Personnel
Actions disponibles pour tous les utilisateurs de la plateforme
A.1 Modifier Mon Profil

Tous les utilisateurs peuvent mettre à jour leurs informations personnelles depuis la page de profil.

Accéder à votre profil
  1. Cliquer sur votre nom ou avatar en haut à droite de l'interface.
  2. Dans le menu déroulant, cliquer sur « Mon profil ».
  3. La page de profil s'ouvre avec vos informations actuelles.
[CAPTURE — Menu profil en haut à droite]
Modifier vos informations personnelles
  1. Sur la page de profil, cliquer sur « Modifier » ou directement sur le champ à modifier.
  2. Mettre à jour les champs souhaités :
    • Prénom et Nom
    • Numéro de téléphone
    • Photo de profil : Cliquer sur l'avatar pour changer la photo (formats acceptés : JPG, PNG — max 2 Mo).
    • Biographie / À propos : Description optionnelle de votre rôle.
  3. Cliquer sur « Enregistrer les modifications ».
  4. Un message de confirmation s'affiche : « Profil mis à jour avec succès ».
Note : L'adresse email et le rôle ne peuvent pas être modifiés depuis le profil. Ces changements doivent être effectués par l'administrateur.
[CAPTURE — Page de modification du profil]
A.2 Changer Mon Mot de Passe

Pour des raisons de sécurité, changez régulièrement votre mot de passe.

Changer le mot de passe depuis le profil
  1. Accéder à « Mon profil » (voir section A.1).
  2. Cliquer sur l'onglet « Sécurité » ou la section « Mot de passe ».
  3. Entrer votre mot de passe actuel.
  4. Entrer le nouveau mot de passe (minimum 8 caractères, majuscule, chiffre recommandés).
  5. Confirmer le nouveau mot de passe dans le champ « Confirmation ».
  6. Cliquer sur « Mettre à jour ».
  7. Un message de confirmation s'affiche. Reconnectez-vous avec votre nouveau mot de passe.
[CAPTURE — Formulaire de changement de mot de passe]
A.3 Réinitialiser un Mot de Passe Oublié

Si vous ne pouvez pas vous connecter car vous avez oublié votre mot de passe, voici la procédure de réinitialisation.

Demander une réinitialisation
  1. Sur la page de connexion, cliquer sur « Mot de passe oublié ? ».
  2. Entrer votre adresse email enregistrée dans le système.
  3. Cliquer sur « Envoyer le lien ».
  4. Un email avec un lien de réinitialisation vous est envoyé (vérifier les spams).
  5. Cliquer sur le lien dans l'email — ce lien est valide 60 minutes.
  6. Sur la page de réinitialisation, entrer votre nouveau mot de passe et confirmer.
  7. Cliquer sur « Réinitialiser ».
  8. Vous êtes redirigé vers la page de connexion. Connectez-vous avec le nouveau mot de passe.
Si vous ne recevez pas l'email :
  • Vérifier le dossier spam/indésirables.
  • Attendre quelques minutes (délai de livraison possible).
  • Contacter l'administrateur pour réinitialisation manuelle.
[CAPTURE — Page « Mot de passe oublié »]
A.4 Accepter une Invitation

Lorsqu'un administrateur vous crée un compte, vous recevez un email d'invitation. Voici comment créer votre accès.

Activer votre compte via invitation
  1. Ouvrir l'email d'invitation reçu (expéditeur : noreply de la plateforme).
  2. Cliquer sur le bouton « Accepter l'invitation » dans l'email.
  3. La page d'activation s'ouvre dans le navigateur.
  4. Vérifier que votre email est correct (pré-rempli).
  5. Entrer votre prénom et nom.
  6. Choisir un mot de passe sécurisé (minimum 8 caractères).
  7. Confirmer le mot de passe.
  8. Cliquer sur « Créer mon compte ».
  9. Vous êtes connecté automatiquement et redirigé vers votre tableau de bord.
Lien d'invitation expiré : Les invitations expirent après 72 heures. Si votre lien est expiré, contactez l'administrateur pour renvoyer une nouvelle invitation.
[CAPTURE — Page d'activation de compte par invitation]
A.5 Se Déconnecter
Déconnexion sécurisée
  1. Cliquer sur votre nom ou avatar en haut à droite.
  2. Dans le menu déroulant, cliquer sur « Se déconnecter ».
  3. Vous êtes redirigé vers la page de connexion.
Bonne pratique : Déconnectez-vous toujours en quittant la plateforme, surtout depuis un ordinateur partagé.
